# ДЗ-2. Бизнес-модель и работы пользователя

> Около 2 часов. Бизнес-модели B2B и B2C будут различаться сильнее, чем кажется. Заполнять с сегмента и ценностного предложения — остальное следствие.
> Перед сдачей проверьте каждый критерий успеха вопросом «быстрее чем что?» или «что изменится в его действиях?». Абстрактные критерии — самое частое замечание.

## Бизнес-модель B2C-варианта

| Блок | Ответ |
|---|---|
| Сегменты — для кого | Частные репетиторы по математике и физике и школьники, которые занимаются сами. |
| Ценностное предложение — какую работу выполняем лучше | Подбираем задачи под тему от простого к сложному. Помогаем разобраться в ошибке через подсказку. |
| Каналы — как доходим до пользователя | Сообщества репетиторов, школьные чаты, рекомендации знакомых. |
| Отношения с клиентами — разовая сделка или подписка | Подписка. Сначала можно попробовать бесплатно. |
| Источники дохода — за что платят | Репетитор или школьник платит за анализ решений, подсказки и индивидуальный подбор задач. |
| Ключевые ресурсы — данные, модель, инфраструктура | База задач и решений, граф шагов и ошибок, модель, сервер. |
| Ключевые процессы — что делаем сами | Разбираем решения на шаги, находим ошибки, подбираем задачи и подсказки. |
| Партнёры — кто делает часть работы | Преподаватели помогают размечать решения. Провайдер модели даёт API. |
| Структура затрат — во что обходится | Разработка, оплата модели и сервера, разметка решений, привлечение пользователей. |

## Бизнес-модель B2B-варианта

| Блок | Ответ |
|---|---|
| Сегменты — для кого | Онлайн-школы по математике и физике. Пользуются методисты, преподаватели и кураторы. |
| Ценностное предложение — какую работу выполняем лучше | Показываем частые ошибки по группе и подбираем следующие задачи каждому ученику. Это сокращает ручную работу. |
| Каналы — как доходим до пользователя | Напрямую через руководителей курсов и методистов. Предлагаем пилот на одной группе. |
| Отношения с клиентами — разовая сделка или подписка | Договор и подписка, помощь с подключением и поддержка. |
| Источники дохода — за что платят | Онлайн-школа платит за массовый анализ и подбор задач. Стоимость зависит от числа учеников. Покупку согласует руководитель продукта. |
| Ключевые ресурсы — данные, модель, инфраструктура | Решения учеников, граф ошибок, модель, сервер и подключение к платформе школы. |
| Ключевые процессы — что делаем сами | Загружаем решения, считаем частые ошибки, формируем отчёты и подбираем задания. |
| Партнёры — кто делает часть работы | Школа даёт задания и решения, её техническая команда помогает с подключением. Провайдер модели даёт API. |
| Структура затрат — во что обходится | Разработка, модель и сервер, подключение школ, поддержка и продажи. |

## Три работы пользователя

> Полный уровень: все восемь элементов по каждой работе. Одна работа — один глагол: «хочу найти, сравнить и выбрать» — это три работы.

### Работа 1

| Элемент | Ответ |
|---|---|
| **Когда:** контекст — особенности человека и ситуации | Я репетитор. Для ученика нужны задачи по изученной теме. |
| **Когда:** негативные эмоции — что чувствует, пока результата нет | Раздражает, что много времени уходит на поиск. |
| **Когда:** известные решения — что уже знает о способах | Учебник, сборники задач, поиск в интернете. |
| **Когда:** триггер — событие, запускающее действие | Разобрали тему, пора дать практику. |
| **Хочу:** ожидаемый результат — «хочу + глагол» | Хочу найти задачи под тему и уровень ученика. |
| **Хочу:** критерии успеха — по чему судит, что вышло | За 5 минут получаю 5 задач по теме от простого к сложному, без поиска по разным сайтам. |
| **Хочу:** процесс перехода — что для этого делает | Указываю тему и ученика, смотрю предложенные задачи. |
| **Чтобы:** работа более высокого уровня — ради чего всё это | Чтобы ученик закрепил тему, а подготовка к уроку занимала меньше времени. |

**Одной фразой:** Когда мы разобрали тему, я хочу найти задачи с подходящей сложностью, чтобы ученик закрепил материал.

### Работа 2

| Элемент | Ответ |
|---|---|
| **Когда:** контекст | Я школьник, решаю задачу сам и застрял на одном шаге. |
| **Когда:** негативные эмоции | Злюсь, что не получается, хочется просто загуглить решение. |
| **Когда:** известные решения | Готовые решения в интернете, помощь учителя или репетитора. |
| **Когда:** триггер | Ответ не сошёлся, а где ошибка — непонятно. |
| **Хочу:** ожидаемый результат | Хочу понять свою ошибку. |
| **Хочу:** критерии успеха | После подсказки сам исправляю шаг и решаю похожую задачу без готового решения. |
| **Хочу:** процесс перехода | Загружаю своё решение, читаю подсказку, пробую ещё раз. |
| **Чтобы:** работа более высокого уровня | Чтобы научиться решать самому и не забыть всё сразу после домашки. |

**Одной фразой:** Когда ответ не сошёлся, я хочу понять свою ошибку с помощью подсказки, чтобы дальше решать самому.

### Работа 3

| Элемент | Ответ |
|---|---|
| **Когда:** контекст | Я методист онлайн-школы. В группе много учеников, просматривать все решения долго. |
| **Когда:** негативные эмоции | Беспокоит, что часть ошибок остаётся незамеченной. |
| **Когда:** известные решения | Ручная проверка, таблицы, статистика правильных и неправильных ответов. |
| **Когда:** триггер | Ученики сдали домашку по новой теме. |
| **Хочу:** ожидаемый результат | Хочу определить самые частые ошибки группы. |
| **Хочу:** критерии успеха | Вижу 3 самые частые ошибки и число учеников по каждой без ручного просмотра всех решений. |
| **Хочу:** процесс перехода | Загружаю решения группы, смотрю отчёт и примеры ошибок. |
| **Чтобы:** работа более высокого уровня | Чтобы доработать объяснение темы там, где ученики чаще ошибаются. |

**Одной фразой:** Когда группа сдала домашку, я хочу определить частые ошибки с примерами из решений, чтобы доработать объяснение темы.

## Сверка

> Модель зарабатывает на том же, ради чего человек выполняет работу? Если модель зарабатывает на одном, а работа про другое — что-то из двух неверно.

Да. В B2C платят за подбор задач и помощь с ошибками. В B2B школа платит за анализ ошибок всей группы и индивидуальные задания без ручного подбора каждому.

---

### Как будет оцениваться

| | |
|---|---|
| **A** | Все блоки бизнес-модели заполнены, монетизация связана с тем, кто и за что платит. Три работы записаны полным составом элементов, критерии успеха конкретны и проверяемы |
| **B** | Бизнес-модель полна; в работах один-два элемента формальны либо часть критериев абстрактна |
| **C** | Бизнес-модель заполнена частично; большинство критериев успеха — пожелания, либо есть многоглагольные формулировки |
| **D** | Работы подменены функциями продукта; бизнес-модель отсутствует или не связана с продуктом |
